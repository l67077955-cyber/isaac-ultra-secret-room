# vibe-coding-showcase

A curated collection of software artifacts built entirely through AI-assisted development (vibe coding):
from a one-sentence brief to a working product. Each exhibit ships as a single, self-contained web page
with no external dependencies and no build step, served via GitHub Pages.

**Live showcase**: https://l67077955-cyber.github.io/vibe-coding-showcase/

## Exhibits

| # | Project | Live demo | Description |
|---|---------|-----------|-------------|
| 01 | Ultra Secret Room Field Guide | [Demo](https://l67077955-cyber.github.io/vibe-coding-showcase/isaac-ultra-secret-room/) | An interactive guide to the Ultra Secret Room in *The Binding of Isaac: Repentance+*, featuring a floor-plan simulator that generates layouts according to the game's actual placement rules |

## Principles

- Each exhibit is a single self-contained HTML file: zero dependencies, zero external assets, works offline
- Interactive behavior is based on mechanics verified against primary sources
- Detailed documentation is provided in each exhibit's directory
